Hospital Corpsman PQS e‑Learning Course (NAVEDTRA 43699‑2A)
A self‑paced, interactive SPA training platform for Navy Hospital Corpsmen.




📘 Overview
This project is a single‑page application (SPA) designed to deliver a complete, interactive e‑learning experience for the Hospital Corpsman Personnel Qualification Standard (PQS), NAVEDTRA 43699‑2A.

It includes:

Modular course content for Modules 101–303

Interactive quizzes

Scenario‑based learning

YouTube video embeds

A clean, responsive UI

No backend required — fully static and GitHub Pages compatible

This platform is intended for training and educational use only and is not an official Navy publication.
